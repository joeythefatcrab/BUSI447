# 447 Prep

A small study app for BUSI 447 (Advanced Corporate Finance, Rice) midterm prep.

- **Course map** that shows how the ten units fit together
- **10 units**, each with a "Start here" intro, the lesson, step-by-step walkthroughs, a "Common confusions" section, a flashcard deck and practice questions
- **29 diagrams and charts** built from the class examples (trees, waterfalls, payoff diagrams, the Nadir trade-off curve…)
- **124 flashcards** with a five-box spaced-repetition system (weakest cards first)
- **150 practice questions** with explanations; pick a quick set of 8 or the full bank, and choices reshuffle on every attempt
- **Mock exam** mode: questions spread across all units, optional timer, results by unit
- **Formula sheet**, plus two interactive widgets (one-step binomial calculator, MM leverage explorer)

Dark theme only, built for phones as well as laptops: on a phone you get a bottom tab bar, large tap targets, and you can add it to your home screen (Share → Add to Home Screen) to use it like an app.

Plain HTML, CSS and JavaScript with no build step. Progress is saved in the browser's localStorage.

## Run it

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

To host it on GitHub Pages: repo **Settings → Pages → Deploy from a branch → main / (root)**.

## Editing content

Core content lives in `data1.js` (units 1–5) and `data2.js` (units 6–10): `lesson` sections, `cards` (`q`/`a`) and `quiz` items (`q`, choices `c`, correct index `a`, explanation `why`). `data3.js` and `data4.js` add the intros, walkthroughs, common confusions, extra questions and the course map. Figures are generated by `make_figs.py` into `figs.js` (`python3 make_figs.py`).

Problem-set answers are worked solutions, not an official key.
